# Hardik DevRoom

An interactive workspace-inspired developer portfolio that showcases my projects, skills, achievements, and coding journey through an immersive developer room experience.

## 🚀 About

Hardik DevRoom is a unique portfolio designed to provide visitors with an engaging way to explore my work. Inspired by a developer's workspace, the portfolio combines creativity with professionalism to highlight my technical skills, projects, and accomplishments.

## ✨ Features

* Interactive workspace-inspired landing page
* Modern and responsive UI
* Project showcase with live demos and source code
* Skills and technology stack section
* Coding profiles and achievements
* Resume download
* Smooth animations and transitions
* Contact section with social links

## 🛠️ Tech Stack

### Frontend

* React.js
* Tailwind CSS
* Framer Motion

### Tools

* Git
* GitHub
* Vite
* Vercel

## 📂 Sections

* Home
* About Me
* Skills
* Projects
* Achievements
* Coding Profiles
* Resume
* Contact

## 📸 Inspiration

The portfolio is designed around the concept of a developer's workspace, where different objects within the room represent various sections of the portfolio, creating a memorable user experience while maintaining easy navigation.
